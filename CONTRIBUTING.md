# Como contribuir para a pesquisa

Obrigado pelo interesse em AYANODE TGU. O foco atual é reprodutibilidade e validação, não a afirmação de capacidades emergentes.

1. Antes de propor alteração relevante, abra uma issue explicando o comportamento esperado, a métrica e como reproduzi-lo.
2. Execute `npm test` e `npm run check` (nenhuma instalação é necessária para esses testes).
3. Para mudanças no núcleo matemático, inclua teste numérico correspondente e descreva os parâmetros usados.
4. Diferencie fatos reproduzidos, hipóteses da TGU/ICOER e interpretações filosóficas.
5. Não envie credenciais, dados pessoais, logs de peers reais ou persistência de salas.

**Licenciamento:** antes de aceitar contribuições de código externo, o mantenedor deve definir a licença do repositório e os termos aplicáveis às contribuições. Até isso acontecer, prefira issues com propostas técnicas e resultados de testes.
